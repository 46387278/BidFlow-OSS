# BidFlow · 投标工作台 1.2.0

面向 ToG/ToB 业务的工程与采购团队，AI 招投标工作台：**项目雷达扫描、标书拆解、标书初稿生成**。

**离线 · 开源**：只用 Python 标准库，不装第三方包、不联网、不上传文件，全部数据留在本机。许可证 Apache-2.0。

---

> **关于本项目的开发方式**：BidFlow 源自我自己的工程业务。代码由我的三个 AI 员工（AutoClaw、WorkBuddy、Codex）协助开发，我负责确定需求、审核公开范围和批准发布。每个版本的验证记录见 Releases 与 GitHub Actions。
>
> —— 老唐，BidFlow 项目维护者

## 下载与启动（三步）

1. 到 [Releases](../../releases/latest) 下载 **`BidFlow_v1.2.0.zip`**

   > ⚠️ 不要下「Source code (zip)/(tar.gz)」。那是源码快照，不含示例标书 `data/sample/sample_bid.docx`，双击 `self_check.bat` 会直接判失败。正式包只有 Release 附件里那一个。

2. 解压到新目录（路径可以带中文和空格，已实测）。装 **Python 3.8 或更高**（3.13 已验）。
   注意：Windows 应用商店那个 `WindowsApps\python.exe` 是占位程序，不算装好 Python。

3. 双击 `self_check.bat` 自检 → 全绿后双击 `start.bat` → 浏览器打开 <http://127.0.0.1:8080/>

## 能做什么

| 模块 | 做什么 |
| --- | --- |
| 标书拆解 | 上传 DOCX 招标文件，抽出评分项、分值合计、废标红线条款，并标出每条在原文的段落位置 |
| 标书初稿生成 | 按评分项生成 Word 初稿：该写的节先立好，缺料的地方明确标「待填」，不用从空白页开始 |
| 项目雷达扫描 | 抓中国政府采购网公开公告，按原始链接去重入库，按地区/金额筛，导出 HTML 和 CSV |

三个结果全部由确定性规则引擎产出，同一份输入得同一份输出——这是能拿去对标的底子。

## 项目雷达扫描（命令行）

在解压目录打开命令提示符：

```bat
python collector\daily.py 办公家具
```

词表与信源在 `config/` 下配置，默认示例为办公家具。见[接入你自己的信源](docs/接入你自己的信源.md)。

在 `data/reports/` 生成需求雷达 HTML 和 CSV。要每天自动跑，用 Windows 任务计划程序建每日任务：程序填 Python 解释器完整路径，参数填 `collector\daily.py 办公家具`，起始目录填解压目录。

离线试用：

```bat
python collector\daily.py --input data\sample\notices.example.jsonl
```

> 公告的资格、金额、投标截止日期，一律以原公告为准。本工具只做筛选，不做判断。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示「没有可用的 Python」 | 没装或只有商店占位版。装 python.org 的 3.8+，重开窗口再跑 |
| 窗口闪一下就没了 | 换成在解压目录的地址栏输 `cmd` 回车，再手打 `start.bat`，能看到报错 |
| 8080 被占 | 改 `config\config.json` 里的 `port`（启动脚本会读这个值，不需要改 `start.bat`） |
| 自检红了 | 把窗口内容整段复制，对照 `docs/常见故障与修复.md`；仍不通就提 Issue 并附这段文本 |

## 已知边界

- **不调用任何大模型**。要「文字更顺」得自己接，接法见 `docs/常见故障与修复.md` 第六节。
- 没有日志文件，窗口一关日志就没了。
- 没有开机自启，每天手动双击一次 `start.bat`。
- 拆解规则对表格结构敏感，遇到拆不出的评分表请提 Issue 并附脱敏后的表头。
