# 接入你自己的信源 · v1.2.0

## 1. 先查公开义务

国务院令第 711 号《中华人民共和国政府信息公开条例》第二十条将财政预算、决算信息以及重大建设项目的批准和实施情况列入主动公开范围。按当地的「重大建设项目政务公开事项标准目录」核对公开责任单位和栏目。[条例原文](https://www.nda.gov.cn/sjj/xxgk/gkzd/0528/20240528170712942213877_pc.html)

找线索可按八个环节排查：项目建议书批复、可研批复、初步设计及概算批复、年度政府投资计划、财政预算支出、采购意向公开、招标公告、中标公告。初设及概算批复通常能帮助确认方案与投资规模，具体项目的审批条件和是否采购应回查当地原件。不同项目的公开时点会有差异。

## 2. 把栏目类型和站点地址分开

先确定文件类型，再去责任单位网站找栏目。例如，寻找初设及概算批复时，从政府信息公开目录里的重大项目批准结果查起。点开数条记录，验证正文与栏目是否相符。把实际列表页地址记录在自己的配置或适配器里。

## 3. 识别三种公开形态

| 形态 | 记录重点 |
| --- | --- |
| 逐条批复 | 项目名、批复日期、金额、原件链接 |
| 批量汇总表 | 项目编码、对应行、公告及附件链接 |
| 审批平台留痕 | 项目名和公开状态。细节不足时只作线索 |

## 4. 采集前做三项核对

1. 抽查列表与正文，确认栏目真实覆盖目标文件。
2. 用 curl 或 urllib 直接请求公开列表，确认响应里有条目。浏览器才显示条目时，查找站方提供的公开接口；没有可用公开方式就停止自动采集。
3. 出现验证码或访问限制就停止。可改为人工查看公开首页，并整理允许访问的条目。

## 5. 处理工程问题

- TLS 握手失败时，先查站方支持的版本。确认站点只支持 TLS 1.2 时，可用 curl 的 `--tlsv1.2 --tls-max 1.2` 诊断，保留证书验证。
- gkmlpt 一类平台可能在前端渲染列表，先核对原始响应，再决定是否有公开接口可用。
- 内置 ccgp 按至少 90 秒间隔发送请求，每批至多 6 次。复用缓存，遵循站方公布的限额。

## 6. 从内置源开始，再接新源

解压后运行 `self_check.bat`。先离线导入样例，生成 `data/reports/` 下的 HTML 和 CSV。

```powershell
python collector\daily.py --input data\sample\notices.example.jsonl
python collector\daily.py 办公家具
```

第二条命令显式访问中国政府采购网全国公开检索。换品类时，把 `config/keywords.example.json` 复制为 `config/keywords.json`，修改 `good`、`bad`、`build` 和 `service`。保留 `build` 为空可取消建设或供货词的正向过滤。使用 `python collector\daily.py --configured` 按源配置检索，命令行关键词优先。

接新源时，写一个 `collector/<标识>_collect.py`，接收位置参数形式的检索词。用 urllib 读取公开列表或接口，输出与 `data/sample/notices.example.jsonl` 相同结构的逐行 JSON。至少填项目名称和原件链接，已核实的阶段填预算立项、采购意向、招标公告或招标结果公布。先用 `daily.py --input` 验证输出，再让适配器调用 `collector/ingest.py <JSONL>`，成功返回 0。把 `sources.example.json` 复制为 `sources.json`，登记标识、启用状态和检索词，验证成功后再设定时任务。

## 7. 合规与数据留存

只采集无需登录的公开信息，遵守 robots、站方规则和频率限制。遇到验证码或认证要求停止自动采集。公告、配置和报表保留在本地。

> 注：四节点编号表示阶段先后。实际提前了多少日历天，需要有下一节点的可靠日期才能计算。
