当前候选版本：v1.2.0。

## 发布检查单（每次发版必须全过，顺序执行，缺一不发）

1. **构建一次**：`tools/build_zip.py`（或当版构建入口）产出唯一候选 ZIP，记录其 SHA-256。
2. **三档装同一份**：Windows CI 矩阵（3.8/3.11/3.13）安装测试必须全部使用**这一个候选 ZIP**，禁止各 job 自行重新构建。
3. **全绿后原包发布**：CI 全绿后，把**同一个 ZIP 原样**上传为 Release 资产，禁止发布前重新构建。
4. **哈希对账**：下载线上 Release 资产，重算 SHA-256，与第 1 步记录值逐位比对，一致才算发布完成。
5. **留痕**：发布记录（提交 SHA、ZIP 哈希、三档 CI 运行链接）写进 Release 正文或 issues，后人可查。

> 背景：v1.1.1 发布时，3.8 档 CI 比 Release 晚 34 秒通过，且无法证明三档测试的就是公开附件那份包。本检查单即为堵这个证据缺口。
